Post title goes here — make it specific and useful

A one or two sentence lede that expands the title. What does the reader get from this post?

Aayush Maggo Apr 14, 2026 12 min read

The problem

Start with why this matters. What's the situation most readers will recognize? Set up the tension before you resolve it.

You can use bold for emphasis, italics for tone, and code for inline snippets. Links look like this.

What I found

Get into the substance. Be specific — numbers, examples, screenshots if you have them. General claims without evidence don't land.

  • First observation or finding
  • Second observation, with more detail if needed
  • Third point — keep list items roughly the same length

Code example (optional)
